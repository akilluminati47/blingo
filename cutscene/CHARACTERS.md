# BLINGO — Character Reference for AI Generation

All characters are **blobs** — rounded, squishy, single-color bodies with simple dot eyes and a mouth.  
Style: low-poly 3D, cel-shaded / soft clay look. Matte surfaces, no reflections.  
Scale: all cousins are 1.0 base; bosses are 2.7x.
